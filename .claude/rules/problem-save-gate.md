# 1단계(문제 저장) 게이트 규칙

`docs/01-problem-save/sessions/**`에 새 세션 파일을 쓰거나, `dev-workflow`
스킬의 명령 1을 실행할 때만 읽으세요.

## 반드시 지킬 것 — PRD 확장 게이트

**Full 등급 + 프로젝트 트랙**이면, 1단계 필드를 다 채운 뒤 2단계로 넘어가기
전에 **"PRD(경량형/상세형)로 확장할지"를 사용자에게 반드시 명시적으로
물어보고, 답변을 세션 파일에 기록한다.** 이 확인 없이 다음 단계로 넘어가지
않는다 — 세션을 다시 시작하거나 재실행하는 경우에도 이 게이트를 건너뛰지
않는다(매번 다시 확인한다).

이유: PRD 확장 여부는 이후 전체 파이프라인의 무게(경량형 5섹션 vs 상세형
11섹션, 2단계 5단계 파이프라인 적용 여부)를 바꾸는 결정이라, AI가 임의로
추정하면 나중에 되돌리기 비싸다. 등급 판단(`scope-tiers.md`)과 마찬가지로
**사람의 명시적 답변 없이 확정하지 않는다.**
