# 코딩마라톤 — AI 요구사항 인터뷰어 (인수인계)

이 폴더는 "2026 대전 코디세이 AI 네이티브 코딩마라톤" 출전 준비물입니다. 다른
서버/세션에서 이어서 작업할 때 이 파일을 먼저 읽으세요. 저장소 전체 규칙은
루트 [`CLAUDE.md`](../CLAUDE.md)를 따릅니다(git 이메일은 noreply, 커밋 전
검증 등).

## 확정된 것

- **주제**: AI 요구사항 인터뷰어 — 막연한 아이디어를 컨텍스트-프리 질문으로
  되물어 EARS 요구사항 목록으로 바꿔주는 대화형 서비스. 대상은 아이디어를
  정리하지 못하는 사람(특히 코딩 초보자).
- **팀**: 3인 — 총괄(질문 시나리오 테스트·발표), AI 활용 가능한 팀원(시스템
  프롬프트·Claude API 연동), 코딩 처음인 팀원(채팅 UI 뼈대, AI 코딩 도구로
  실습).
- **제출 양식**: DDBM 캔버스(데이터 기반 비즈니스 모델). 칸은 개요, 미션, 핵심
  활동, 핵심 파트너, 핵심 장벽, 가치제안, 부정적 영향, 혜택, 핵심 이네이블러,
  핵심 데이터, 비용, 수익. 현장 캔버스 사진으로 확인함.
- **구조**: 웹 채팅 UI ⇄ Claude API(시스템 프롬프트) → EARS 목록. 별도 DB 없이
  대화 기록만 유지. 서비스로 쓰려면 Anthropic API 키가 필요하다(Claude Code
  세션은 다른 사용자가 못 씀).
- **MVP 범위**: 대화 인터뷰 → 끝나면 EARS 요구사항 일괄 생성. 답변마다 실시간
  갱신과 diff 승인 UI는 V1.5, PDF·XLSX 첨부는 V2.
- **차별점**: 매니패스트는 객관식 + 문서 첨부 + 내러티브 PRD. 우리는 자유
  서술형, 모호한 답을 숫자로 재질문, EARS 구조화 출력.

## 아직 안 정해졌거나 못 받은 것

- **비용·수익 칸**: 팀에서 두 칸의 내용이 정해졌다고 했지만 내용을 전달받지
  못했다. `ddbm-canvas.html`의 두 칸은 초안이다. 받으면 교체한다.
- **해커톤 공고문과 심사 기준**: 원문이 없어서 기준 적합성 확인을 못 했다.
  사용자에게 공고문을 다시 받아서 `plan.html`과 항목별로 대조한다.
- API 키 발급 주체와 예산 한도, 발표 데모용 예시 아이디어.

- 이 폴더는 공개 저장소 `gamercross/coding-marathon`에도 올라가 있다(사용자가

  폴더에 넣지 않는다.
