AI 요구사항 인터뷰어

막연한 아이디어를 컨텍스트-프리 질문으로 되물어 구조화된 요구사항으로 바꿔주는 대화형 인터뷰 서비스.

2026 대전 코디세이 AI 네이티브 코딩마라톤 팀 3인 제작 기간 6시간
01

개요

아이디어는 있지만 "무엇을, 왜, 어떻게" 정리해서 말하지 못하는 사람(특히 코딩 초보자)이 대상입니다. AI가 정형화된 질문을 한 번에 1~2개씩 던지고, 답변에 따라 다음 질문을 좁혀가며 막연한 요청을 구체적인 요구사항으로 다듬습니다.

원문제새 프로젝트를 시작할 때마다 즉흥적으로 접근하고, 요구사항이 애매한 채로 개발이 시작돼 나중에 다시 만든다.
목표대화 4범주(동기·범위·성공기준·메타)로 되물어, 개발 착수가 가능한 수준의 요구사항 목록을 자동 생성한다.
근거Gause & Weinberg, Exploring Requirements (1989) — 컨텍스트-프리 질문 / IEEE 830 정량화 규칙
02

핵심 메커니즘

시스템 프롬프트가 자유 대화를 좁은 절차로 강제합니다 — 받아 적기가 아니라 되묻기.

"당신은 요구사항 인터뷰어입니다. 사용자가 막연한 아이디어를 말하면 받아 적지 말고 아래 4범주로 되물어서 구체화하세요: 1. 동기/배경 — 왜 이걸 만들려는지, 기존 대안으로는 왜 부족한지 2. 범위/환경 — 누가 쓸지, 더 큰 시스템의 일부인지 3. 성공 기준 — '빠르다/편하다' 같은 표현이 나오면 숫자로 되묻기 4. 메타 — 마지막에 '안 물어봤지만 알아야 할 게 있나요?' 한 번에 1~2개씩만 묻고, 끝나면 EARS 문형으로 정리하세요."
03

아키텍처

채팅 UI가 Claude API를 직접 호출하는 얇은 구조. 대화 기록만 유지하면 되고 별도 DB는 필요 없습니다.

API 키가 필요합니다. Claude Code나 claude.ai 세션은 로그인한 사람만 쓸 수 있어, 다른 사람이 브라우저로 접속해 쓰는 서비스가 되려면 앱이 자체적으로 Anthropic API 키를 갖고 호출해야 합니다. 개발 중 코딩 보조로 Claude Code를 쓰는 것과는 별개입니다.

매니패스트와의 차이

항목매니패스트우리

06

이건 그냥 챗봇 아닌가

밑바닥 기술은 챗봇이 맞지만, 자유 대화가 아니라 강제된 절차이고 대화 자체가 아니라 구조화된 산출물이 목적이라는 점이 다릅니다.
