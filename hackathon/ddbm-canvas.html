AI 요구사항 인터뷰어

DDBM 캔버스 (Data-Driven Business Model) · 대전 코디세이 코딩마라톤

개요Model title

막연한 아이디어를 컨텍스트-프리 질문으로 되물어, 개발자가 바로 읽을 수 있는 요구사항 명세(EARS)로 바꿔주는 대화형 인터뷰 서비스.

미션Mission

아이디어를 말로 정리하지 못하는 사람도 개발에 착수할 수 있게 한다. 요구사항 정리의 진입장벽을 낮춘다.

핵심 활동Key activities

  • 4범주 질문(동기·범위·성공기준·메타)으로 대화 진행
  • 모호한 답변을 숫자로 재질문
  • EARS 요구사항 목록 생성
  • 변경분 승인(diff) 화면 제공

핵심 파트너Key partners

  • Anthropic (Claude API)
  • 해커톤 주최·멘토
  • 코딩 교육기관·부트캠프
  • 외주·에이전시(명세 수요처)

핵심 장벽Key barriers

  • 범용 챗봇·PRD 도구와의 차별화
  • LLM 응답 품질 편차(질문 이탈·환각)
  • API 비용·외부 의존
  • 사용자가 답을 짧게만 하는 문제

가치제안Value proposition

  • 아이디어만 말하면 개발자가 바로 읽는 명세가 나온다
  • "빠르다·편하다" 같은 표현을 측정 가능한 숫자로 확정한다
  • 대화가 아니라 구조화된 결과물이 남는다
  • 요청 크기에 따라 인터뷰 깊이가 달라진다

부정적 영향Negative impacts

  • AI 질문에 기대 스스로 정리하는 힘이 약해질 수 있음
  • 입력한 아이디어의 유출·오용 위험
  • 틀린 요구사항을 자신 있게 출력할 위험

핵심 이네이블러Key enablers

  • Claude API (대화·구조화 출력)
  • 컨텍스트-프리 질문 방법론을 담은 시스템 프롬프트
  • EARS / IEEE 830 출력 규칙
  • 웹 채팅 UI

핵심 데이터Key data

  • 대화 로그(아이디어·답변)
  • 모호 표현 → 정량화 질문 패턴
  • 생성된 요구사항 명세

혜택Benefits

  • 요구사항 누락·재작업 감소
  • 개발 착수까지 시간 단축
  • 비개발자의 참여 확대

비용Costs초안

  • API 호출비 — 대화 1회당 토큰 비용(측정 후 기재, 예산 한도 미정)
  • 호스팅·서버
  • 프롬프트 개선·시나리오 테스트 시간
  • 인건비(팀 3인)

수익Revenues초안

  • 무료 체험 + 프리미엄 구독(무제한 인터뷰·문서 내보내기)
  • 교육기관·팀 단체 라이선스
  • 에이전시용 API(화이트라벨)

비용·수익 칸은 팀에서 정한 내용으로 교체할 초안입니다. 나머지 칸은 기획서의 내용을 캔버스 칸에 맞춰 옮긴 것입니다.
