## 판정 기준

- **채택** — 우리 rules/hooks/agents 체계에 정식으로 편입. `CLAUDE.md` 라우팅
  표와 `.claude/rules/consistency.md`의 기준 파일 지도에도 반영됨.
- **격리** — 자기 폴더 밖의 어떤 파일도 건드리지 않는다는 게 확인된 채로,
  독립적으로만 동작. 우리 라우팅 표·기준 파일 지도는 그대로.
- **제거** — 실효성 없음 또는 충돌 확인 → 삭제, 근거만 남김.
